# 🏠 Smart Home Security - Node-RED

Sistema IoT de seguridad para el monitoreo y control de una vivienda, desarrollado con **Node-RED** y un dashboard interactivo.

El proyecto centraliza diferentes componentes de seguridad del hogar, permitiendo visualizar el estado general del sistema, detectar eventos mediante sensores, controlar accesos y consultar información desde una interfaz gráfica.

## 🚀 Funcionalidades

* 🔐 Sistema de alarma para el hogar.
* 📡 Monitoreo de sensores PIR para detección de movimiento.
* 🚪 Control y supervisión de puertas y ventanas.
* ⚠️ Indicador dinámico del nivel de riesgo.
* 📊 Dashboard interactivo para monitoreo en tiempo real.
* 🕒 Historial de eventos registrados por el sistema.
* 🔋 Visualización del estado de la batería.
* 🏠 Representación visual del hogar mediante un gemelo digital.
* 🎮 Modelo 3D interactivo dentro del dashboard.
* 📱 Integración con Telegram para notificaciones del sistema.
* 📱 Diseño adaptable para distintos tamaños de pantalla.

## 🛠️ Tecnologías utilizadas

## ▶️ Uso del proyecto

1. Instalar Node-RED.
2. Iniciar el entorno de Node-RED.
3. Acceder al editor desde el navegador.
4. Seleccionar **Import → Clipboard**.
5. Copiar o importar el contenido de `Seguridad_Casa.json`.
6. Instalar los nodos adicionales requeridos por el flujo.
7. Configurar las integraciones y dispositivos correspondientes.
8. Ejecutar el flujo mediante **Deploy**.

> Las credenciales, identificadores privados y configuraciones sensibles deben configurarse localmente y no almacenarse directamente en el repositorio.

## 🎯 Objetivo

El objetivo del proyecto es aplicar tecnologías IoT y programación basada en flujos para desarrollar una solución centralizada de monitoreo y seguridad residencial, integrando sensores, visualización de información, gestión de eventos y mecanismos de notificación.
